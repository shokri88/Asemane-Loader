# پری‌لودرهای آسمانه

فایل index.html را مستقیم در مرورگر باز کنید. هیچ نصب، build، کتابخانه، CDN یا اتصال اینترنتی لازم نیست.

## فایل‌ها
- index.html، demo.css و demo.js: فقط گالری نمونه‌ها.
- preloader.css و preloader.js: کامپوننت مستقل برای انتقال به پروژه.
- assets/logo.png: لوگوی اصلی شما، بدون تغییر.
- example.html: نمونه اتصال با نمایش آزمایشی ۲٫۵ ثانیه‌ای.

## نصب
CSS را در head بگذارید. JavaScript و فراخوانی را بلافاصله پس از باز شدن body قرار دهید تا پیش از محتوای اصلی اجرا شود. مسیرها را مطابق پروژه خود تغییر دهید.

```html
<!-- داخل head -->
<link rel="stylesheet" href="/preloader/preloader.css">

<!-- بلافاصله پس از باز شدن body -->
<script src="/preloader/preloader.js"></script>
<script>
  const loader = AsmaneLoader.create({
    variant: 'line',
    theme: 'light',
    logo: '/preloader/assets/logo.png'
  });
</script>
```

به‌طور پیش‌فرض پس از رویداد window.load حذف می‌شود. روی صفحات کش‌شده ممکن است بسیار کوتاه یا اصلاً دیده نشود؛ تأخیر مصنوعی برای سایت واقعی اضافه نشده است. بیشینه انتظار پیش‌فرض ۱۰ ثانیه است تا سایت پشت لایه بارگذاری نماند. در صورت غیرفعال بودن JavaScript هیچ لایه مسدودکننده‌ای ساخته نمی‌شود.

## کنترل دستی برای دریافت داده یا SPA
```js
const loader = AsmaneLoader.create({
  variant: 'frame', autoHide: false, maxWait: 10000
});
try {
  await loadYourPageData(); // تابع واقعی پروژه خودتان
} finally {
  loader.hide(); // محو شدن و حذف از DOM
}
// برای حذف فوری هنگام unmount یا تغییر مسیر:
// loader.destroy();
```
هر فراخوانی یک نمونه جدید می‌سازد. برای هر بار بارگذاری یک نمونه بسازید و هنگام پایان یا unmount آن را حذف کنید. تایمر و listener نمونه پاک می‌شوند. مدت maxWait مثبت و برحسب میلی‌ثانیه است؛ صفر و مقدار نامعتبر به ۱۰۰۰۰ برمی‌گردند.

## تنظیمات
| گزینه | پیش‌فرض | توضیح |
|---|---|---|
| variant | line | نام نمونه از جدول بالا |
| theme | light | light یا dark |
| logo | assets/logo.png کنار فایل JS | مسیر تصویر |
| size | 154 | عرض لوگو، پیکسل |
| speed | 2.4 | طول چرخه برحسب ثانیه؛ مدار دو برابر است |
| accent | رنگ قهوه‌ای ملایم | رنگ خط یا نقطه |
| background | مطابق تم | رنگ پس‌زمینه |
| label | در حال بارگذاری | متن برای صفحه‌خوان |
| autoHide | true | حذف پس از بارگذاری صفحه |
| maxWait | 10000 | مهلت ایمنی برای حالت تمام‌صفحه |
| inline | false | نمایش داخل target به‌جای تمام صفحه |
| target | document.body | عنصر میزبان |

CSS فقط کلاس‌های asm- را هدف می‌گیرد و فونت، margin، scroll و سبک پروژه شما را تغییر نمی‌دهد. تم تیره لوگوی سیاه اصلی را با CSS سفید می‌کند؛ برای لوگوی رنگی این filter را حذف کنید. انیمیشن‌ها با prefers-reduced-motion متوقف می‌شوند. خطوط بارگذاری تزئینی هستند و درصد واقعی دانلود را نشان نمی‌دهند. از مرورگرهای مدرن استفاده کنید.

پری‌لودر تمام‌صفحه یک نشانگر وضعیت است، نه modal تعاملی؛ اگر در اپلیکیشن خود محتوای تعاملیِ آماده زیر آن دارید، مدیریت focus/inert را در چرخه بارگذاری همان اپلیکیشن انجام دهید. دمو برای پیش‌نمایش این کار را انجام می‌دهد.

## پیشنهاد
برای سایت معماری «خط معماری» یا «قاب آسمانه» انتخاب‌های ساده‌تری هستند. هیچ فایل demo را برای استفاده در سایت اصلی نیاز ندارید.

## نسخه دوم: حرکت روی خود لوگو
شش نمونه جدید در گالری: draw، assemble، weave، pulse، type و signature.
خطوط و سه کلمه زیر نشان از همان تصویر اصلی با CSS جدا و متحرک می‌شوند؛ فونت جایگزین استفاده نشده است. این برش‌ها مخصوص لوگوی آسمانه هستند و برای لوگوی دیگری باید تنظیم شوند. مدل‌های قبلی همچنان از API در دسترس هستند.

```js
AsmaneLoader.create({ variant: 'signature', size: 190 });
```
